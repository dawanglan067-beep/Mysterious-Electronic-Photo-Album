# 覆盖原图与备份恢复说明

本说明对应 A4b 当前实现。普通“导出图像”和“另存为素材”继续生成副本，保护源文件。

## 覆盖原图

打开照片，完成裁剪、旋转或调色后，点击右侧“覆盖原图…”。确认窗口列出实际源路径、备份位置、JPEG 重编码与元数据限制。默认选取消；只有明确确认才执行。

程序先校验源文件未被外部修改，创建并验证完整备份，再安全替换源文件。成功后重新读取磁盘结果作为新原图，清空旧撤销历史；原图对比和恢复全部原图此后对应新保存版本。需要旧版本时使用备份恢复，不依赖 Ctrl+Z。

PNG、JPEG、BMP 仅在运行时编解码器支持且扩展名与真实格式相符时允许覆盖。JPEG 默认质量 95，透明区域白底；会重新编码。高位深、CMYK、符号链接、超过 512 MiB 的源文件暂不支持覆盖，使用导出副本。EXIF 方向加载时规范化，识别的颜色配置转换为 8 位 sRGB 处理；未标记图像按 sRGB 解释。拍摄时间、GPS、其他元数据与广色域保真不保证保留。

## 找到和恢复备份

备份默认保存在应用 AppDataLocation/backups 下，确认窗口和成功提示会显示实际位置。它不应位于已打开相册内；出现此冲突时覆盖被拒绝，先导出副本。不要将备份目录作为相册打开。备份不是图片，不能只改扩展名来使用。

点击“备份与恢复…”，选择当前照片的版本，再选“恢复为新副本”。选择与原图相同扩展名、尚不存在的路径，程序校验容器及哈希后写出覆盖前的原始文件字节。当前源图和编辑保持不变；恢复副本不自动加入相册，可自行打开或导入。

该菜单也可打开备份目录或永久删除已选的单个备份。删除前再次确认，取消不删除。当前不自动清理，容量由用户主动管理；清理前可复制整个备份目录到其他磁盘。AppData 可能随系统或应用数据清理而丢失，不能代替长期外部备份。

## 失败时的处理

源文件外部变化、备份不可写或校验失败、编码或提交失败时，程序保留编辑并说明失败步骤；先重新加载或导出副本。磁盘占用时关闭占用该文件的程序后再试。

若提示“已替换但验证失败”，磁盘文件已可能变化；不要把它理解为原图未改动。程序保留内存编辑和备份，可先另存当前结果，再使用备份恢复为新副本。检查与替换不是跨进程锁，在保存时避免同时用其他软件修改同一文件。

程序尚未完成 A5 全局离开提醒，覆盖确认不能替代切图、关闭或退出时的统一保护。实际目录窗口、不同磁盘环境和部署后的格式能力仍须按总计划手工验收。
