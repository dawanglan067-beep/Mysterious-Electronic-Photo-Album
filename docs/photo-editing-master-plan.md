## 一 总目标与版本边界

建立两条衔接的流程：单图修图为“打开照片 → 裁剪旋转调色 → 对比与撤销 → 导出副本或另存素材 → 经确认覆盖源图”；多图合成为“新建画布 → 添加图层 → 排列与变换 → 保存可编辑工程 → 导出成品”，后续增加选区与蒙版。

矩形裁剪改变画面范围，图层拼合组合多张图片，选区和蒙版提取局部。完成矩形裁剪不代表完成多图合成或抠图。

| 交付版本 | 必须完成的范围 | 明确边界 |
| --- | --- | --- |
| V1 基础修图 | A1–A5，含 A4a、A4b；方向与输出策略；单图验收 | 不含多图合成；素材管理 R 独立验收 |
| V2 多图拼合 | B1–B3，保留 V1；可交付的工程与安全导出 | 普通透明叠加，不承诺复杂混合、PSD 或蒙版 |
| V3 手动抠图 | C 阶段选区、蒙版、画笔和工程保存 | 手动提取局部，不称为自动人物分割 |
| 后续增强 | D 融合与排版；E 独立研究 | 每项另定范围，不计入前三版默认承诺 |

不在 V1 收尾期间继续扩充相册管理需求；已交付的删除和目录功能继续维护。没有用户指定期限，不编造排期；工期在核心原型、目标机器和验收工作量明确后估算。

## 四 共享规则与状态边界

### 文档与界面各自拥有的状态

PhotoEditDocument 唯一拥有单图源图、参数与几何编辑状态；PicShow 协调编辑命令和 QUndoStack。PhotoCanvas 拥有显示缓存及缩放、平移、临时对比状态，源图快照只读；PhotoAdjustmentPanel 展示参数并发出信号，不保存另一份可编辑文档。

CompositionDocument 独立拥有合成画布、不可变资源及图层状态，不把多张图塞入单图字段。树控件继续拥有唯一相册节点、收藏、筛选和导航。服务与协调器通过公开接口交换数据，不使用 friend 或共享全部私有字段绕过边界。

### 历史与重置

单图历史记录 EditState 前后状态；一次连续滑块拖动、裁剪确认或完整变换只形成一步。程序回填控件阻断信号，取消不提交命令，新编辑清除旧重做分支。返回基准内容时恢复相应未修改判断，不能只靠历史索引猜测图像是否变化。

“还原参数”只清除调色和滤镜；“恢复全部原图”清除全部单图编辑，操作本身可撤销。原图对比只影响显示，释放后恢复结果及视图，切图、清空、隐藏和失活时结束对比。

### 导出状态与保存基准

单图区分“内容相对加载基准有变化”和“当前编辑是否已有合格输出”。A5 拟在成功全尺寸导出或素材另存后记录对应状态及输出信息；当前状态与已输出状态一致时可按规则允许离开，内容修改标记仍如实保留。导出后继续编辑、撤销至其他状态、取消或失败均不能误判为已处理。缩略图和预览截图不算合格输出；实现时明确输出记录有效性策略。

另存素材保留原始编辑源和历史。覆盖原图仅在提交成功且读取实际结果验证通过后，才建立新源图、默认 EditState 和新基准，并清空旧历史。Ctrl+Z 不跨源图版本恢复，覆盖前版本通过备份恢复。此后“原图对比”和“恢复全部原图”均指新基准。

合成工程保存成功才更新工程基准；导出 PNG/JPEG 不代替工程保存。图层属性、排序、蒙版及画布设置属于内容；当前选择和窗口视图不属于内容修改。

### 图像处理定位

当前单图顺序为“源图裁剪 → 镜像 → 90 度旋转 → 可选预览降采样 → 调色”。预览降采样用于交互，导出从完整源图和文档状态重新渲染，不使用画布缓存或窗口截图作为成品。

当前为 8 位处理，不宣称 RAW/HDR、无损 JPEG 编辑或完整专业色彩管理。代码尚未显式完成 EXIF 方向规范化与输出色彩转换；sRGB 是拟实现策略，不能据此声称当前已经保色。超出支持范围须明确说明或拒绝，不能静默产生错误结果。

## 五 V1 基础修图要求

### 现有功能与补齐项目

V1 保留亮度、对比度、饱和度及已有滤镜；支持 90 度旋转、镜像、撤销重做、原图对比和恢复全部原图。裁剪提供自由比例、原图比例、1:1、4:3、3:2、16:9，使用原图整数像素边界；左键操作，八个控制点，确认或取消，旋转镜像后结果一致。

导出默认 PNG 副本，提供 JPEG 质量设置；BMP 在运行时编码器可用时支持。透明 PNG 保留透明；单图 JPEG 明确合成白色背景。普通导出和素材另存阻止目标指向源图，其他已有输出也应先确认。A4a 默认 PNG 编号命名，可选加入当前相册，连续提取不清空源图或历史。

V1 收尾须补齐 EXIF 方向的显式策略：解码时规范化到可见像素或采用等价可靠方案，记录规范化后的尺寸与坐标，保证裁剪、对比、导出和重新加载一致，不重复旋转。测试涵盖旋转及镜像方向，不能仅靠当前 QImage::load 推断已处理完成。

输出色彩策略须有代码和样本验证：对可识别配置文件按既定工作空间转换并标注输出；缺失配置文件说明默认解释；不支持的色彩空间与高位深须提示降级或拒绝。V1 目标为 8 位 sRGB 输出，不承诺 CMYK、16 位或广色域保真；目标经实现和测试后才可标为完成。

任意角度拉直、编辑草稿、复杂抠图、图层合成、RAW/HDR 和 AI 不属于 V1 必须范围。

## 六 A4b 覆盖原图方案

本节为下一新增功能的实施约束，尚未实现。覆盖原图会替换磁盘源文件，必须与普通导出分开；删除素材同样涉及磁盘改动，不能称覆盖是全程序唯一文件风险。备份提供恢复途径，不是无限保留或绝对防故障承诺。

### 格式 元数据与外部修改决策

首批覆盖仅支持经验证的 PNG、JPEG、BMP，要求扩展名、实际格式、读取与写入能力相符。WebP、GIF、CMYK、16 位及其他不能可靠往返的文件先导出副本，不仅改扩展名伪装支持。支持矩阵经 T16、T19、T20 验证后写入说明书。

覆盖 JPEG 默认质量 95，提示重新编码可能有损。提交后以实际重新解码像素建立基准，不用提交前未压缩 QImage 冒充磁盘结果。EXIF、拍摄时间、GPS 及其他元数据逐项验证；不能保留时覆盖前提醒，推荐另存副本，不能因 QImageWriter 成功而宣称元数据完整。

加载或建立基准时记录规范路径、文件身份相关信息、大小、修改时间和内容哈希。大小与时间只作快速筛查，临近提交重新验证内容哈希，同大小同时间的外部修改也须识别。操作期间变化、读取失败、占用或归属不明时中止，提示重新加载或另存。检查与提交间仍有竞争窗口；QSaveFile 解决安全替换，不等于跨进程并发锁，不能承诺彻底消除外部并发修改。

### 备份位置 保留与恢复

建议默认使用 QStandardPaths::AppDataLocation 下的 backups，须检查实际路径不在受扫描相册内。若有目录包含或路径别名冲突，要求另选位置或中止，避免备份被当作照片扫描。

按源身份分组，用唯一版本 ID 保存备份；清单记录原路径、时间、格式、大小和内容哈希等。同名而不同目录的照片不能共用备份槽位。备份完整写入并校验后才可提交，不覆盖既有版本。备份异常、空间不足或取消，保留原文件及当前编辑。

建议每个源身份保留最近 20 版，并保留近 30 天版本，取两者并集。这是清理规则，不是实时磁盘硬上限。V1 首版只提供用户主动清理，不静默删旧备份；清理前显示范围、占用和后果。空间不足不得绕过备份，阈值按实测再调整。

须提供可发现的备份入口与“恢复为副本”流程，验证哈希及可读性；若允许恢复覆盖当前源，需再次确认并先备份当前版本。AppData 可能随系统或应用数据清理丢失，不代替长期外部备份；说明书写明位置和手动复制方法。

### 覆盖事务与失败分支

1. 从完整文档状态渲染，完成格式、路径、源身份与外部修改校验；确认无冲突保存任务。
2. 告知覆盖路径、格式和质量、元数据限制、备份位置及历史将清空；取消不改变文件和状态。
3. 创建唯一备份并校验与当前源一致；临近提交再查源未变化，变化或失败不沿用过时确认。
4. QSaveFile 写入并禁用直接写入回退，检查编码和 commit。提交失败保留旧源、备份及内存编辑，准确报告失败步骤。
5. 成功提交后读取实际磁盘结果，核对格式、尺寸、可解码性和预期内容；通过后更换源、默认参数、清历史及更新基准。
6. 刷新编辑器、照片墙和树缩略图，增加资源版本或请求代号，丢弃旧异步结果。

提交前失败须保留原文件和编辑。提交成功但重读验证失败时，磁盘可能已经更换，不能提示“原图未改动”；保留内存和备份，不清历史、不重建基准，给出重新加载、另存内存结果与备份恢复入口。程序异常退出后也须能通过持久化清单找到备份，不依赖会话临时变量。

| T12 | 相册导入打开关闭及音乐、PDF | 受影响核心流程无回归；可听输出另验 |
| T13 | 多次裁剪另存、命名和可选登记 | 源和历史保留，文件列表正确，不重复登记 |
| T14 | 保存成功但登记失败或取消 | 分别报告文件与登记结果，不误删输出 |
| T15 | 备份、写入、提交故障及恢复 | 提交前源不变，可从已验证备份恢复 |
| T16 | 外部同大小同时间修改及格式不符 | 哈希检查拦截，不误覆盖变化中的源 |
| T17 | JPEG 新基准及提交后重读失败 | 基准来自磁盘像素，准确处理已提交失败分支 |
| T18 | 旧缩略图任务与快速切图 | 旧任务不回写，新图与磁盘一致 |
| T19 | EXIF 旋转 90 180 270 度及镜像 | 显示、尺寸、裁剪、保存重开一致，不重复处理 |
| T20 | CMYK、16 位、WebP、GIF、大图及配置文件 | 支持项符合策略；不支持明确降级或拒绝，不崩溃 |

### V1 必做实机验收

真实鼠标完成左键裁剪、八点拖动、确认取消、缩放平移、对比和撤销；在 100% 与 200% 缩放及多显示器下重复关键操作。原生文件窗口检查取消、格式选择、已有输出确认、素材保存和登记。

用临时照片验证覆盖、备份发现、恢复为副本、外部修改提示及 A5 所有离开入口。验证真实相册导入、取消、关闭、PDF、音乐和打包运行；离屏能启动不代表这些流程通过。部署到目标 Windows，确认 Qt 插件和编解码能力与说明书一致。

整应用发布另执行 R 的删除、目录及回收站恢复实机验收。故障注入只用可丢弃临时样本，不在真实个人照片上测试破坏性分支。

## 八 B 阶段多图拼合

### B1 文档与最小渲染

新建可设像素宽高、背景色或透明背景的画布，尺寸与窗口分离。引入不可变图片资源及稳定图层 ID，先完成两图按层序透明叠加，验证重叠像素、透明度和输出尺寸，再扩交互。

### B2 图层工具与历史

支持一次添加多图，每张独立图层；初始通过变换缩放到可见区域，不改源像素。列表支持选择、重命名、显隐、锁定、复制、删除和上移下移，上方对应画面前方。

支持移动、等比例缩放、任意角度旋转和数值输入，提供确认取消；首版避免无意翻转与零缩放。透明度为 0–100%，仅普通透明叠加。增删、排序、属性、变换与画布设置全部可撤销，连续拖动一步。

### B3 工程与安全交付

保存工程后重开可继续编辑，原素材移动后工程仍可用。全画布 PNG/JPEG 从完整资源渲染，透明 PNG 保留透明，JPEG 按明确背景合成并提供质量设置。退出提供保存工程、放弃、取消，失败或取消不得丢失编辑。

典型流程为新建 1920×1080 画布、加入背景与前景、调整位置大小角度、修改层序和透明度、保存工程、重开编辑、导出成品。该尺寸是示例，不是上限。

V2 首版不含自动抠图、复杂蒙版、曲线、文字、图层组、透视、独立图层裁剪、RAW/HDR、PSD、AI 和云上传。局部素材先由 V1 裁剪另存，图层源坐标裁剪留到 D。

## 九 C D E 阶段

### C 选区 蒙版与手动抠图

先矩形和椭圆选区，再多边形套索；支持添加、减去、反选、清除和羽化。选区转当前图层蒙版，可保留或隐藏所选。蒙版绑定源图坐标，黑隐藏、白显示、灰部分透明，保留源图资源。

增加擦除与恢复画笔，提供大小、硬度、强度，一笔一步；支持临时禁用、删除、反相和独立查看蒙版。蒙版随图层变换，保存后可继续编辑。验收走通手动选主体、换背景、修边、保存重开和导出，不能以矩形截图代替抠图。

### D 融合与布局增强

逐项增加少量混合模式、每层调色、源坐标图层裁剪、对齐吸附、等间距和拼图布局；文字、水印、投影与图层组按需求再定。先定义资源、渲染顺序、工程兼容和历史边界，再实现验证，不一起塞进大类。

### E 独立研究

RAW、高位深、HDR、复杂修复和 AI 先做独立原型，评估质量、速度、部署体积、授权和硬件。现有 8 位管线不能靠新增按钮升级成专业影像流程。

## 十 合成架构与坐标约定

| 模块 | 责任 |
| --- | --- |
| CompositionDocument | 画布、资源、稳定 ID 图层、内容基准与选择 |
| ImageLayer | 资源、名称、变换、显隐、锁定、透明度；后续蒙版等 |
| CompositionCanvas | 预览、命中、坐标转换和临时交互 |
| LayerListModel | 展示图层，修改通过文档命令 |
| CompositionCommand | 状态与资源引用，接入 QUndoStack |
| CompositionRenderer | 统一定义生成预览和完整画布 |
| CompositionProjectStore | 版本化保存、资源校验和分阶段加载 |
| ImageExportService | 共用编码与安全机制，不共用不适配的单图历史 |
| SelectionTool 与 MaskTool | C 阶段选区和蒙版交互 |

命令引用不可变资源，移动一次不复制全图。删除图层后历史持有恢复资源，文档和历史均无引用时才释放。合成工作区独立协调，不继续堆入 PicShow。

区分源图像素、合成画布像素和窗口逻辑坐标。视图缩放平移只影响最后映射，不改图层位置或输出。以源图中心为锚点，保存画布中心、缩放和角度；命中按层序逆向查找，用逆变换映射回源坐标。首版可按变换矩形命中，透明穿透后续增强；锁定层可列表选择但不可拖改。

渲染顺序为“解码并规范方向 → 可选源坐标裁剪 D → 图层调色 D → 蒙版与源透明度结合 C → 图层变换 → 图层透明度及混合 → 按层序叠加”。未支持阶段视为恒等。蒙版和裁剪绑定规范化源坐标，裁剪只限可见区域；变更顺序须升级格式或迁移，不静默改变旧工程结果。

预览与导出共用几何和合成定义，预览可降分辨率；导出用完整资源和明确平滑模式，不承诺未验证的特定插值核。后台只处理 QImage 和数据，不操作 GUI；请求身份和文档版本检查阻止旧结果覆盖。

## 十一 合成工程格式与文件安全

V2 建议单文件容器，包含文件标识、版本、JSON 清单和资源区，以 QSaveFile 提交；QDataStream 固定版本与字节序。这是待原型验证的设计，不是已存在格式或完成实现。

资源记录稳定 ID、长度、编码、尺寸和校验信息，规范字段和上限；CRC 发现意外损坏，不作为恶意篡改防护。检查总大小、声明长度、偏移、数量、解码像素与整数溢出，防止坏工程耗尽内存。

内嵌原始编码及必要方向信息，或明确的无损规范表示；不依赖开发机绝对路径，不每保存一次重压 JPEG。蒙版随工程保存；重开无需恢复完整撤销历史，建立已保存基准即可。

加载先解析到临时结构，完成版本、长度、资源和必要渲染校验后才替换当前文档。损坏、未知版本、资源缺失和取消不破坏当前工程。保存成功才更新基准；撤销回同样的已保存内容应恢复未修改。

导出拒绝覆盖任何输入资源与当前工程，保护实际路径别名。已有输出先确认，QSaveFile 禁用直接回退，失败不损坏旧文件。保存工程、图片导出和源图覆盖各有明确提示语义。

## 十二 性能测量与风险控制

以下仅为原型测量目标，尚无当前达标证据，不保证任意电脑达标。固定目标 CPU、内存、系统、Qt 构建、格式、滤镜、画布与源尺寸，记录冷启动或缓存、计时起止、重复次数、延迟分布和进程峰值内存。

| 场景 | 初始测量目标 | 必须记录的边界 |
| --- | --- | --- |
| 单图交互预览 | 参数响应不超过 100 ms | 预览像素、滤镜、缓存及连续拖动 |
| 8000×6000 导出 | 不超过 10 s；峰值目标 1 GB | 约 4800 万像素，格式、质量、磁盘和基线内存 |
| 裁剪反馈与 4K 十图层预览 | 不超过 50 ms | 交互反馈或已缓存预览，不是任意全尺寸重算 |
| 二十图层工程打开保存 | 不超过 5 s | 每层源尺寸、编码和解码总体积及缓存 |
| 连续切换五十次 | 稳定后无持续增长趋势 | 排除预热，记录稳定区间与关闭后任务释放 |

单张 8000×6000 四通道 8 位缓冲约 183 MiB，多份源、结果、历史、编码和备份读回会叠加。先限制像素、资源数和并行任务，复用不可变资源，不据此承诺无限图层。根据实测确定公开尺寸上限与提示。

风险包括 EXIF、颜色解释、元数据、JPEG 重编码、磁盘备份不足、外部修改、旧异步结果、大图内存及部署编解码差异。通过失败注入、明确拒绝和实机样本验证；期限受限先缩小格式与容量范围，不跳过文件保护和验收。

## 十四 R 素材删除与目录管理

R 从旧 A4a-D 独立整理，功能仍保留维护。删除移动相册内实际文件到系统回收站，成功才同步树、照片墙、收藏、缓存和导航，重开不再扫描出现。外部导入只删相册副本，外部源保留；取消、占用或回收失败保留节点并报告。

删除当前编辑图片前可导出副本、放弃编辑继续删除或取消。输出不能落入待删文件集合或目录，不能把刚保存的结果一起删掉。批量部分成功逐项反映，不能将整批当作全成全败。

真正空素材目录默认隐藏，判断包括隐藏及非图片文件；磁盘目录保留。子目录可独立隐藏或整目录回收，不绑定父相册关闭；根始终可见，可显示已隐藏目录。隐藏仅本次运行有效，重开重新扫描，不等同删除；新素材登记创建或重新显示必要目录。

| 新编号 | 旧编号 | 场景与要求 |
| --- | --- | --- |
| R01 | T19 | 删除后重开：实际文件已回收，不再出现 |
| R02 | T20 | 外部导入：只删相册副本，源保留 |
| R03 | T21 | 取消和占用失败：磁盘、节点、编辑保留 |
| R04 | T22 | 当前编辑和异步：保护、导航、缓存同步 |
| R05 | T23 | 空目录：真正为空才隐藏，根保留 |
| R06 | T24 | 隐藏、显示和新登记：不关闭父相册 |
