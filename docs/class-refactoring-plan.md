# 类职责拆分计划与实施记录

日期：2026-10-27

## 目标与约束

先拆分 ProTreeWidget 中边界明确的业务规则、查重界面，以及 MainWindow 中的删除协调流程，再拆单图画布与调色面板。拆分必须迁移实际职责，不通过 friend 或共享全部私有字段绕过边界。

树控件继续拥有唯一一份树节点、收藏、筛选和导航状态。PhotoEditDocument 继续拥有唯一一份原图与编辑状态，QUndoStack 的历史语义保持。文件保存成功与树登记成功分别报告。每一轮完成构建和相关回归，再扩大范围。

## 第一轮已实施

| 模块 | 接管的职责 | 输入和输出 | 不承担的职责 |
| --- | --- | --- | --- |
| MaterialImportService | 验证素材、相册路径归属、外部文件复制、哈希去重和编号避让 | 素材路径与相册路径 → 成功、相册内实际路径或错误 | 不访问树、控件、收藏或编辑文档；不判断相册是否已在界面打开 |
| DuplicateReviewDialog | 匹配报告、缩略图展示、勾选与输出待处理路径 | 指纹与匹配值 → 勾选路径列表及窗口接受/取消结果 | 不保存树节点指针，不执行磁盘删除，不维护导航 |
| AlbumDeletionController | 单张、批量及整目录删除确认、编辑保护调用、结果汇总 | 树和编辑器公开接口、请求路径 → 执行既有删除流程与提示 | 不复制树或编辑状态；不访问私有成员，不拥有照片节点 |

ProTreeWidget::RegisterMaterial 保留“相册已打开/忙碌”判断、登记节点、恢复目录显示、修复导航及通知刷新；磁盘准备移交 MaterialImportService。相同素材去重仍复用原文件；不同内容同名仍避让，源文件保留。

ProTreeWidget::SlotDetectDuplicates 保留范围选择和算法调用，报告展示交给 DuplicateReviewDialog；窗口只返回路径，随后发出与照片墙相同的删除请求。MainWindow 只创建和连接 AlbumDeletionController，删除确认和结果提示从构造函数移出。

本轮明确的行为调整：查重清理由原先 QFile::remove 永久删除改为复用回收站删除流程，包含当前编辑保护、失败保留节点、统一导航和缓存同步。没有勾选路径时禁用清理按钮。普通删除与目录管理入口维持原有行为。

第一轮规模：ProTreeWidget.cpp 从 1574 行降至 1364 行；MainWindow.cpp 从 314 行降至 271 行。行数仅用于观察职责迁移，不作为拆分验收标准。

## 第二轮已实施

| 模块 | 实际拥有的内容 | 与 PicShow 的边界 |
| --- | --- | --- |
| PhotoCanvas | 预览显示缓存、原图只读共享快照、输出尺寸及 HUD 展示数据、缩放/平移/拖动/对比视图状态 | 接收渲染结果，独立绘制和处理鼠标交互；通过信号更新缩放文字和请求编辑器焦点，不访问编辑文档或撤销栈 |
| PhotoAdjustmentPanel | 三个调色滑块、滤镜控件和数值标签 | 发出参数变更和手势起止信号；程序回填参数时阻断控件信号，不自动产生编辑或历史 |

PicShow 继续独占 PhotoEditDocument 和 QUndoStack，处理加载、修改状态、命令提交、裁剪与保存。面板只展示参数，未增加第二份编辑状态。画布所持原图是 QImage 隐式共享的显示快照，绝不修改源像素；没有读取 PicShow 私有字段或通过 friend 绕过边界。

picshow.ui 中原 QLabel 提升为 PhotoCanvas，保留 label 对象名、QLabel 兼容性和布局尺寸策略，不通过 setPixmap 使图像尺寸污染控件 sizeHint。画布负责显示缓存，PicShow 更新直方图和元数据时只读取该预览；缩小预览仍只用于滑块拖动过程，全尺寸渲染和保存仍来自文档。

一次滑块拖动仍由 PicShow 记录开始状态，在释放时提交一条历史；键盘调色、滤镜、还原及撤销重做通过文档回填面板。原图对比只改变画布显示，释放恢复缩放和平移；切图、清空、隐藏和失活结束对比。额外补齐画布焦点丢失时终止拖动，以及小尺寸预览下按实际完整输出尺寸计算 1:1 缩放。

第二轮规模：PicShow.cpp 从 1191 行降至 903 行，PicShow.h 从 151 行降至 133 行。PhotoCanvas 与 PhotoAdjustmentPanel 均可独立于编辑器实例运行。原先规划中的“取色”在当前单图画布没有独立功能入口，本轮未新增该能力。

第二轮验证：Album 与 AlbumFeatureTests 构建通过；常规 ctest（10.45 秒）及 QT_SCALE_FACTOR=2 离屏回归均零失败，整页 editor-components.png 已检查。新增独立面板参数同步与手势信号检查、独立画布缩小预览下的 1:1 比例、滚轮、左键平移、对比释放视图与源像素保护、失焦拖动恢复及隐藏/清空检查。原有历史、键盘快捷键、裁剪、旋转镜像、源图对比、重置加载、素材保存/删除、查重、相册与 PDF 回归一同通过。尚未完成真人鼠标、多显示器、系统回收站恢复与实际音频输出验收。

## 第三轮已实施

提取 AlbumLoadController，集中相册打开和追加导入的任务调度、进度窗口、取消等待及重入打开队列。打开扫描使用临时根节点，线程结束且未取消时才提交到树；导入成功才合并新节点，取消时由原线程回滚本次新文件和临时节点。完成后树控件仍是节点、收藏、筛选、导航和工作区设置的唯一所有者；控制器不保存第二份相册状态。

ProTreeWidget 保留来源目录选择、完成后的节点选中与界面刷新。关闭相册、删除和素材登记在任务进行时拒绝操作，避免节点在后台引用期间释放。来源相册内部路径由控制器验证；目录选择窗口返回后重新按路径寻找目标节点，不沿用可能失效的旧指针。

验证：Album 与 AlbumFeatureTests 构建成功；最终常规 ctest 用例约 11.02 秒、总耗时约 11.03 秒，200% 离屏 Failures: 0。新增重入打开排队、重复打开、导入自身拒绝、成功导入、重复导入、取消导入回滚、取消打开无半成品及取消后重开检查。既有相册、修图、素材、查重、PDF 和音乐设置回归通过；重开相册截图已检查。真实鼠标、系统回收站恢复和可听音频仍待实机验收。
