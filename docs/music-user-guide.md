# 背景音乐使用说明

## 支持范围

程序支持普通、未加密的以下音频文件：

- WAV（PCM）
- MP3
- FLAC
- M4A
- AAC
- OGG
- WMA

QQ 音乐的 `.qmc`、`.mgg`、`.mflac` 等加密文件不在支持范围内。仅修改文件扩展名不能解密文件。

## 添加音乐

1. 打开“背景音乐设置”。
2. 点击“选择/更换音乐文件”。
3. 选择上述格式的普通音频文件。
4. 勾选“选定音乐文件后立即开始播放”可自动试听。

如果文件不存在、大小异常、扩展名不支持或文件头与扩展名冲突，程序会拒绝选择并显示原因。

## 播放后端

程序优先使用 Windows 原生媒体后端播放本地音频。WAV、MP3 等兼容格式可使用 Windows 原生音频引擎；FLAC、AAC、OGG 等格式交给 Qt Multimedia 后端处理。两条路径都失败时，设置窗口会显示具体错误，日志中会输出 `[MusicPlayer]` 错误信息。

## 提交和测试建议

提交程序时必须保留部署目录中的 `multimedia/windowsmediaplugin.dll` 和 Qt Multimedia 依赖 DLL。建议在交付前用 WAV、MP3、FLAC 各测试一首，并确认默认 Windows 音频输出设备可用。

不同 Windows 版本对少见编码的支持可能不同。交付给老师时，建议优先使用普通 MP3、WAV 或 FLAC 文件；对不支持的文件，程序应提示转换为这些格式，而不是直接改文件后缀。
